# فاحص الشبكة

برنامج لعرض الأجهزة المتصلة بشبكتك وفحص سرعة الإنترنت على Windows.

## التنزيل

[**نزّل البرنامج**](https://github.com/AneesAdwan/NetScanner-Releases/releases/latest/download/NetScanner-win-Setup.exe)، ثم افتح الملف. لا يحتاج أي برنامج إضافي ولا صلاحيات مدير، والتحديثات تصلك تلقائياً داخل البرنامج.

إذا ظهر تحذير Windows SmartScreen اضغط "مزيد من المعلومات" ثم "تشغيل على أي حال".

استخدم البرنامج على شبكتك أو شبكة لديك إذن بفحصها فقط.
