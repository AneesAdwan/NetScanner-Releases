# MTC Network Manager

برنامج مجاني من MTC Group لإدارة أجهزة شبكتك على Windows: اكتشاف الأجهزة وخريطة الشبكة والمراقبة والتنبيهات والتقارير وحجب الإعلانات. كل بيانات شبكتك تبقى على جهازك.

## التنزيل

[**نزّل البرنامج**](https://github.com/AneesAdwan/NetScanner-Releases/releases/latest/download/NetScanner-win-Setup.exe)، ثم افتح الملف. لا يحتاج أي برنامج إضافي، والتحديثات تصلك من داخل البرنامج. من يستخدم فاحص الشبكة يصله هذا الإصدار كتحديث، وتنتقل أسماء أجهزته معه.

إذا ظهر تحذير Windows SmartScreen اضغط "مزيد من المعلومات" ثم "تشغيل على أي حال".

استخدم البرنامج على شبكتك أو شبكة لديك إذن بفحصها فقط.
