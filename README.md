# MTC Network Manager

برنامج مجاني من MTC Group لإدارة أجهزة شبكتك: اكتشاف الأجهزة وخريطة الشبكة والمراقبة والتنبيهات والتقارير وحجب الإعلانات. كل بيانات شبكتك تبقى على جهازك.

## Windows

[**نزّل البرنامج لـ Windows**](https://github.com/AneesAdwan/NetScanner-Releases/releases/latest/download/NetScanner-win-Setup.exe)، ثم افتح الملف. لا يحتاج أي برنامج إضافي، والتحديثات تصلك من داخل البرنامج. من يستخدم فاحص الشبكة يصله هذا الإصدار كتحديث، وتنتقل أسماء أجهزته معه.

إذا ظهر تحذير Windows SmartScreen اضغط "مزيد من المعلومات" ثم "تشغيل على أي حال".

## Ubuntu

[**نزّل ملف .deb**](https://github.com/AneesAdwan/NetScanner-Releases/releases/download/linux-v1.5.1/mtc-network-manager_1.5.1_amd64.deb) واضغط عليه مرتين، أو من الطرفية:

```bash
sudo apt install ./mtc-network-manager_1.5.1_amd64.deb
```

أو استخدم [ملف AppImage](https://github.com/AneesAdwan/NetScanner-Releases/releases/download/linux-v1.5.1/MTCNetworkManager.AppImage) بدون تثبيت، وهو يحدّث نفسه:

```bash
chmod +x MTCNetworkManager.AppImage
./MTCNetworkManager.AppImage
```

على Ubuntu يعمل البرنامج بالوضع الداكن، وإغلاق النافذة يغلقه، فالمراقبة تعمل ما دامت النافذة مفتوحة.

---

استخدم البرنامج على شبكتك أو شبكة لديك إذن بفحصها فقط.
